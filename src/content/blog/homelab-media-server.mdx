A walkthrough of how I set up my homelab media server from scratch. This covers using a mini PC as the Docker host, storing all media on a NAS, deploying Jellyfin for streaming, wiring up Sonarr, Radarr, and Prowlarr to automate content management, using qBittorrent as the download client, and tying it all together with Jellyseer so anyone on the network can request movies and shows.
